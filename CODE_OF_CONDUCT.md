# Code of Conduct

状态：根目录协作行为边界。

## 1. Expected Behavior

- Be direct, specific, and evidence-based.
- Focus on product quality, security, maintainability, and user value.
- Respect file ownership and do not revert others' work without explicit approval.
- Report risks, failed tests, and uncertainty honestly.
- Keep security-sensitive information private.

## 2. Unacceptable Behavior

- Hiding failed tests or unverified work.
- Claiming production readiness without evidence.
- Publishing secrets, credentials, private repository contents, or raw sensitive artifacts.
- Making broad unrelated refactors during focused work.
- Harassing, insulting, or derailing collaborators.

## 3. Enforcement

The Human Founder and Master CEO Agent can reject or block contributions that violate this code. Reverting another contributor's work still requires explicit authority and preservation of evidence.

Security violations must follow `SECURITY.md`.
