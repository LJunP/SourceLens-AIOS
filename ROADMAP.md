# SourceLens AIOS Roadmap

- Strategy: `SourceLens AIOS Strategic Constitution v2.3`
- Current phase: `P0 Strategic Foundation`
- Current facts: `docs/aios/truth/project_state.yaml`

## Year-one outcome

Build and scientifically evaluate one trustworthy software-engineering Agent:

```text
Repository revision + Issue
  -> Environment Understanding
  -> Planning
  -> Isolated Execution
  -> Testing
  -> Independent Verification
  -> Risk and Rollback Evidence
  -> Patch Evidence Package
  -> Human Approval
```

The first product is not an AI company, generic Agent framework or broad engineering console. It is a controlled real-issue experiment and evidence loop.

## Phase route

| Phase | Indicative horizon | Objective | Exit evidence |
| --- | --- | --- | --- |
| P0 Strategic Foundation | now | Freeze truth, migration, evaluation and reviewable source baseline | Founder-reviewed P0 gate packet |
| P1 Agent Evaluation and Research Foundation | weeks 2-8 | TaskSpec, snapshots, traces, evaluator and Baseline Suite | reproducible B0/B1/B2 report and hidden-set protocol |
| P2 Repository Intelligence | months 2-4 | task-conditioned repository structure, symbol, relation and context understanding | context benchmark beats simple retrieval baselines |
| P3 Single-Agent Runtime + Minimum Trust | months 3-6 | planner, executor, tools, state, checkpoint/resume, permission and trace | deterministic resume/isolation/action-control tests |
| P4 Software Engineer Agent Alpha | months 5-8 | real issue to verified evidence package | verified patches on controlled real tasks |
| P5 Trustworthy Execution Hardening | months 6-9 | sandbox, approval, audit, policy, risk and rollback hardening | adversarial and recovery evidence |
| P6 Reliability Research | months 8-12 | SourceLens-Bench, failure taxonomy and reliability report | reproducible public/internal benchmark artifact |
| P7 Memory and Learning Research | months 10-15 | working, project and experience memory experiments | A/B or ablation proof of practical improvement |
| P8 Multi-Agent Organization Research | months 12-18 | determine when multiple Agents beat one Agent | declared success/cost/latency/coordination tradeoff |
| P9 Organization Runtime | months 18-24 | identity, capability, delegation and organization memory | governed organization experiments |
| P10 Platformization | years 2-3 | extract stable SDK, tool and environment protocols | second implementation uses the platform |
| P11 Second-Domain Validation | years 2-4 | test whether abstractions generalize | reproducible evidence in another domain |
| P12 AI Organization OS | years 3-5 | governed autonomous organizations | long-term outcome, not current commitment |

The dates are planning ranges, not promises. Evidence gates control phase entry.

## Current P0 sequence

3. Establish the machine-readable Truth Registry.
4. Review the KEEP/REFACTOR/FREEZE/CANDIDATE_ARCHIVE migration ledger.
5. Freeze TaskSpec, Baseline Suite and Evaluation Protocol.
6. Partition the dirty worktree into reviewable checkpoints without reverting user work.
7. Complete independent migration review.
8. Present the P0 gate packet to the Founder.

## Frozen during P0

- new product features and broad P9 UI work;
- GitHub App, webhook, private-repository and enterprise expansion;
- multi-tenant SaaS, organization RBAC and billing;
- broad CI/PR-governance feature expansion;
- memory, learning or multi-Agent product claims;
- deletion of legacy code or governance history.

Urgent security or data-integrity containment may interrupt this freeze only with evidence and an explicit bounded task.

## Required research artifacts

- P1 Evaluation Foundation report;
- P2 Repository Context Benchmark;
- P6 Software-Agent Reliability report;
- P7 Memory Ablation study;
- P8 Single-Agent versus Multi-Agent study.

Every artifact must retain its hypothesis, dataset, source/environment snapshot, baselines, evaluator, raw results, uncertainty, cost, failures, decision and reproduction command.

## Stop rule

Stop rather than expand when a phase cannot beat its declared baseline within budget, cannot reproduce its evidence, violates a trust guardrail or adds complexity without practical benefit.

Pre-v2.3 P6/P9/P10/P11/P12-pre labels are historical and are not part of this roadmap.
