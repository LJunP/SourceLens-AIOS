# SourceLens 演示脚本

> AIOS v2.3 状态：`LEGACY DEMO / FROZEN`。该十分钟产品演示不证明第一年可信 Agent 闭环；P4 前不得把它作为当前产品成功标准。

## 演示目标

在 10 分钟内完整展示 SourceLens 从注册到 PR 风险审查的主链路。

## 推荐演示仓库

| 仓库 | 说明 |
|------|------|
| spring-projects/spring-petclinic | 经典 Spring Boot 示例,结构清晰 |
| bequeath-app/sourcelens-analyzer | 本项目自身,展示自分析能力 |

## 演示流程 (10 分钟)

### 1. 注册登录 (1 分钟)

1. 打开 `http://localhost:5173`
2. 点击「注册」,输入用户名/邮箱/密码
3. 自动跳转仪表盘,显示空状态

### 2. 创建项目 (1 分钟)

1. 进入「项目管理」,点击「新建项目」
2. 输入项目名称: `Spring PetClinic`
3. 描述: `经典 Spring Boot 示例应用`

### 3. 添加仓库 (1 分钟)

1. 进入项目详情 → 「仓库管理」Tab
2. 点击「添加仓库」
3. 输入 URL: `https://github.com/spring-projects/spring-petclinic`
4. 默认分支: `main`

### 4. 触发扫描 (2 分钟)

1. 点击「触发扫描」按钮
2. 状态从 PENDING → RUNNING → SUCCESS
3. 查看扫描结果:
   - 文件树: 按目录结构展示
   - 语言统计: Java / HTML / CSS 占比
   - API 清单: Controller 端点列表
   - 数据库实体: JPA Entity 提取

### 5. 查看架构报告 (1 分钟)

1. 进入「架构报告」Tab
2. 查看模块依赖图
3. 节点: 类/方法/字段
4. 边: 调用/继承/实现关系

### 6. 创建 Agent 任务 (1 分钟)

1. 进入「Agent 任务」页面
2. 选择「架构审查」类型
3. 关联刚完成的扫描任务
4. 提交任务,查看执行步骤和输出

### 7. Issue 拆解 (1 分钟)

1. 进入「Issue 拆解」页面
2. 新建需求拆解:
   - 标题: `支持用户头像上传`
   - 描述: `需要支持用户上传头像,包括裁剪和压缩功能`
3. 提交后查看拆解结果:
   - 需求理解
   - 影响模块
   - 子任务列表
   - 工时预估

### 8. CI 诊断 (1 分钟)

1. 进入「CI 诊断」页面
2. 新建诊断:
   - 工作流名称: `CI Build`
   - 失败日志: 粘贴一段 Maven 编译错误日志
3. 查看诊断结果:
   - 错误分类 (编译/测试/依赖...)
   - 根因分析
   - 修复建议

### 9. PR 风险审查 (1 分钟)

1. 进入「PR 审查」页面
2. 新建审查:
   - PR 标题: `添加用户头像上传功能`
   - 变更文件: `UserServiceImpl.java, AvatarController.java`
3. 查看审查结果:
   - 风险等级
   - 合并建议
   - 行级评论

### 10. 仪表盘总结 (0.5 分钟)

1. 回到仪表盘
2. 展示统计数据:
   - 项目总数
   - 扫描总数
   - 成功/失败统计
   - 最近扫描记录

## 演示要点

- **空状态**: 每个页面首次打开都有友好的空状态提示
- **加载状态**: 所有异步操作都有 Spin 加载动画
- **错误处理**: 操作失败有明确的错误提示
- **数据流转**: 从仓库 → 扫描 → 分析 → Agent 任务,数据完整闭环

## 常见问题

### Q: 扫描很慢?
A: 首次扫描需要 clone 仓库,取决于网络速度。建议使用较小的仓库做演示。

### Q: 分析器找不到?
A: 确保 `sourcelens-analyzer` 已编译到 `target/release/` 目录,或者在 `application.yml` 中配置正确路径。

### Q: 数据库连接失败?
A: 运行 `make deps` 启动 MySQL,等待 5 秒后重试。
