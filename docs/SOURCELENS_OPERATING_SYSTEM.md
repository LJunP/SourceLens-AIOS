# SourceLens AIOS Operating System

This file is the compatibility entry for the former SourceLens virtual-company operating system.

The pre-v2.3 company simulation, 62-definition system and P6/P9/P10/P11 execution route are historical. They do not govern current work.

## Canonical operating stack

1. `aios/truth/project_state.yaml` - current facts, phase, gates and evidence references.
2. `aios/STRATEGIC_CONSTITUTION.md` - mission, year-one outcome, non-goals and phase route.
3. `aios/MASTER_EXECUTION_PROTOCOL.md` - authority, roles, workers, task lifecycle and review.
4. `aios/EVALUATION_PROTOCOL.md` - TaskSpec, baselines, traces, evaluator and research artifacts.
5. `aios/MIGRATION_LEDGER.yaml` - inherited-asset disposition.
6. `AGENT_DECISION_REGISTER.md` - append-only decision rationale.

## Operating loop

```text
Canonical truth
  -> active phase objective
  -> falsifiable task contract
  -> value/evaluation/architecture/security review
  -> temporary specialist implementation
  -> independent verification
  -> integration decision
  -> evidence and truth update
  -> Founder gate when required
```

## Current mode

Current phase: `P1 Agent Evaluation and Research Foundation`.

P0 is complete by Founder Gate decision. P1 entry is authorized, but the current
AIOS-P1-001 contract must be completed, hash-frozen, independently reviewed and
separately started by the Founder before implementation or runs. P1 does not
permit normal feature development, deletion, broad runtime expansion or
multi-Agent product construction.

## Hard rules

- One active critical path.
- One task owner and one file owner.
- One physical Agent role/context per task.
- Implementer and independent verifier are different.
- Capability claims use evidence levels, not progress prose.
- Current facts live once in machine-readable truth.
- Decisions live in append-only ADRs.
- Historical ledgers are not current-state databases.
- Failed experiments may stop; they do not trigger automatic feature expansion.

Role definitions are in `TEAM_OPERATING_MODEL.md`. Detailed rules are in `aios/MASTER_EXECUTION_PROTOCOL.md`.
